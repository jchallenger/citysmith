        What to paste
        
        
          
          
        
        
        
         
        
        
        
          
          
        
        
        
        
          The list is every <stem>-paste-order.txt in the
          output directory. That manifest is the order, and it is
          not filename order: the chunk covering the anchor cell is
          written last so the anchor is still bare board for every paste
          before it.
        
        
      
        

      
        
        Run
        
        
          
        
            
            
          
        
          
        
            
            
          
        
        
        
        
        
          Two captures a chunk — one with the slab in hand, one after it
          lands. On a hundred-chunk town that is two hundred grabs, so thin
          them here; the first and the last are always kept.
        
        
      
        

      
        
        Before it starts
        
        
          
          
        
        
        
          
        
          
          An unreadable probe is not a pass.
          planestate answers off, ON or
          UNKNOWN, and only an explicit off starts a
          run. A build plane makes every chunk land a course high with nothing
          wrong in any file.
        
          
      
          

      
          
        
        
      
          
      
          
        This drives TaleSpire's window: it makes a new board, pitches the
        camera straight down and commits every chunk at one cursor cell.
        Do not touch the mouse or the keyboard while it runs.
